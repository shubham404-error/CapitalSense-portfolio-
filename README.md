# CapitalSense Website

Research-first public website for CapitalSense.

- Brand accent: Electric blue
- Typography: Plus Jakarta Sans
- Visual style: institutional + editorial + minimalist technology
- Themes: light, dark and system

## Routes
Home, About, Services, Research, Insights, Ecosystem, Connect, Disclosures, Privacy and Terms.

## Development
Install dependencies with `npm install`, then run `npm run dev`.

## Before launch
Verify founder biography, ARN/EUIN, empanelments and contact details. Replace placeholder article cards with reviewed content. Configure secure server-side enquiry and newsletter providers. Complete legal, privacy, regulatory and accessibility reviews.
