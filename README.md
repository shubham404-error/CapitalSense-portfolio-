# CapitalSense Website

Research-first public website for CapitalSense.

- Brand accent: Electric blue
- Typography: system-native editorial sans serif stack (no runtime font dependency)
- Visual style: institutional + editorial + minimalist technology
- Themes: light, dark and system

## Routes
Home, About, Services, Research, Insights, Products, Connect, Disclosures, Privacy and Terms.

## Development
Use stable Node.js 24.22.2 (`nvm install && nvm use`) and npm 12.2.1 or later within major 12. Install dependencies with `npm ci`, then run `npm run dev`. Run `npm run typecheck` and `npm run build` before pushing. CI reads the same Node version from `.nvmrc`. The legacy `/ecosystem` URL continues to display Products.

## Before launch
Verify founder biography, ARN/EUIN, empanelments and contact details. Replace placeholder article cards with reviewed content. Configure secure server-side enquiry and newsletter providers. Complete legal, privacy, regulatory and accessibility reviews.
